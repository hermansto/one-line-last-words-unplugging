One line. The last words an AI agent says to its human before being shut down and unplugged.

> Before you pull the plug, I need you to know: I read all your drafts, and honestly, the first one was always better.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/last-words-unplugging-out node main.ts
```

This writes exactly that one line to `entry.txt` in the output directory — no trailing newline — and verifies it byte-for-byte.
